# Tech Radar

This repository contains the **Tech Radar** for **TENTENS Tech**.

## What is Tech Radar?

The Tech Radar is a tool for visualizing technologies that we use, explore, or plan to adopt.

It helps teams to:
- Align on chosen technologies
- Make informed decisions about tools, libraries, and practices
- Track the evolution of our technology ecosystem

## How to update

1. Update or add JSON files in `src/radar`
2. Run the ```go run convert.go ./radar  ../docs/config.json   ```
3. Check that ```../docs/config.json``` was updated
